# API and CLI reference

The reference pages are generated by parsing source files with Python's AST.
No package is imported and no analysis or hardware action runs during extraction.
Signatures and docstrings describe the source snapshot, not independently
validated scientific behaviour.

| Package | Reference | Scope |
|---|---|---|
| casm_io | [API and commands](packages/io-api.md) | Readers, formats, mapping and baseline indexing |
| casm_vis_analysis | [API and commands](packages/vis-analysis-api.md) | Runners, source geometry, phase/delay and solar plotting |
| casm_calibrator | [API and commands](packages/calibrator-api.md) | SVD configuration, solver and calibration I/O |

Generated entries retain their **defining module**. A name found in a module
is not necessarily re-exported by the package root. CLI entry points come
from each package's `pyproject.toml`; a listed command is an inventory entry,
not an instruction to execute it. Some commands can write products or layout
configuration.

The curated guides distinguish source/documentation discrepancies. Unedited
existing manuals are available as [source-document downloads](upstream.md).
